# mediaplayer 多媒體撥放器

按瀏覽按鈕可開啟資料夾選取影片，須按撥放影片才會開始。

導入影片後等待程式跑好，螢幕會出現就緒，可以按下撥放按鈕，播放後出現影片詳情。

按下暫停、停止螢幕左下角也會出現相關資訊。

有額外做了視窗關閉確認事件。
